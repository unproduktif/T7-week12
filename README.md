# Week 12 Task — Supermarket Sales Dashboard

A desktop dashboard app built for a Visual Programming course assignment. It loads the "Supermarket Sales" Kaggle dataset with Pandas and displays it as a data table, KPI summary (total sales, transactions, average rating), and Matplotlib bar/pie charts inside a PySide6 window. It also supports filtering by city, customer type, gender, and payment method, and exporting the charts as PNG.

## Tech Stack

Python, PySide6, Pandas, Matplotlib, QSS for styling.

## How to Run

1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `python main.py`
3. The dashboard loads `data/supermarket_sales.csv` automatically on startup.
